Interleaved frame-disjoint groups A/B/C; identical rays, weights and voxels for all three.

Extraction: 3159 frames, 8.9 MB/frame (28.2 GB); coarse-probability reproduction max |dp| 0.0037, argmax agreement mean 0.9993; SAM refinement changes 6.9 % of pixel labels.
